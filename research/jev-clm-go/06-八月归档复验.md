# 2026-08-20npzs.tgz：新数据复验与 Q 标签可用性

日期：2026-09-27。此报告延续 [第一次真实数据试验](05-真实数据试验.md)的**相同小 CNN、等参数头、训练预算和 MPS 设备**；比较的是各归档内部的两种头，不能拿不同搜索 teacher 的绝对损失直接比较棋力。

## 1. 归档合同与固定抽样

用户提供的 `2026-08-20npzs.tgz` 保持原样，SHA-256 为 `b541cb0e499b03a9d4aaf180eab000f3855cede5281047d796ab6bf604a857dc`。[全包清点](runs/2026-09-27-aug20/archive_census.json)由 [`census_tar.py`](census_tar.py)不解压地读取 gzip tar 得到：**36,252 个 NPZ，2,126,234 行，其中 1,493,750 行为完整 19×19（70.25%）**；目录路径、字段与形状检查无错误。数据都在一个模型名子目录，归档不含实际模型权重或生产配置，目录名不能替代权重 SHA。

| 目标格式 | 文件 | 原始行 | 完整 19×19 行 |
| --- | ---: | ---: | ---: |
| `globalTargetsNC [N,64]` / v2 | 15,336 | 900,318 | 637,328 |
| `globalTargetsNC [N,80]` / v3 | 20,916 | 1,225,916 | 856,422 |

全部 NPZ 都有 `qValueTargetsNCMove [N,3,362]`。KataGo [官方写盘代码](https://github.com/lightvector/KataGo/blob/352de42b663862251343d863cb6d6edb11c122cc/cpp/dataio/trainingwrite.cpp#L597-L662)和[读取器](https://github.com/lightvector/KataGo/blob/352de42b663862251343d863cb6d6edb11c122cc/python/katago/train/data_processing_pytorch.py#L11-L23)确认 v3 在旧 64 列后扩展，现有探针用到的行权重、policy 目标标志与棋局哈希仍位于原列。审计器现按 `(64, v2)` 或 `(80, v3)` **成对**校验，不把新列当模型输入。

在看指标前，按归档成员路径 SHA-256 排名取前 **1,800 个 NPZ**；这是根据全包平均每文件约 41 个 19 路行，预先取接近上次 7.3 万行的预算，不按标签选文件。[抽样清单](runs/2026-09-27-aug20/sample_manifest.json)记录源包及全部选中文件哈希，实际 NPZ 在 Git 忽略的本目录 `data/` 中。

[深审结果](runs/2026-09-27-aug20/audit.json)：1,800/1,800 文件通过，106,717 原始行中排除 30,991 个非 19 路行，余 **75,726 行**；其中 v2 32,929 行、v3 42,797 行。全部原始行有有效 policy0 和正行权重；样本 v3 行的重分析标志均为 0。按局哈希共有 1,116 个完整 19 路棋局，重复 `(局哈希, 回合)` 行为 10,129 个，故独立单位仍是棋局。与首次归档的**两个抽样子集**相比，所有棋局哈希的交集为 0；这不证明两份完整归档全无重叠。

## 2. 相同预算的 MPS 对照

[训练记录](runs/2026-09-27-aug20/main/manifest.json)采用 `d=256`、batch 128、AdamW 学习率 `1e-3`、种子 11/29/47、两组各 5 轮、验证交叉熵选轮次；模型参数均为 15,616 主干 + 302,337 头。整局哈希新切分 `clm-v1-aug20-main-2026-09-27`：训练 888 局 / 59,806 行，验证 102 局 / 7,155 行，测试 126 局 / 8,765 行。M5 Pro / PyTorch 2.14.0 MPS 完成总耗时约 **65.2 秒**。

| 锁定测试集指标，3 种子均值 | 相似度头 | 等参数线性头 | 相似度头减线性头 |
| --- | ---: | ---: | ---: |
| 访问分布交叉熵，越低越好 | 4.89599 | 4.89978 | **−0.00378 nats**（约 −0.077%） |
| 对 teacher 的 KL，越低越好 | 3.89845 | 3.90223 | −0.00378 nats |
| teacher top-1 一致率，越高越好 | 6.218% | 6.028% | +0.190 个百分点 |

按种子配对的测试交叉熵差值为 `+0.00449`、`−0.01467`、`−0.00116` nats：**1 个种子更差，平均差值接近零**。第一次归档同口径的内部差值为 `−0.04228` nats，故原先固定 362 着法相似度头的微弱优势**没有在这份新数据上稳定复现**。两份数据的 teacher、模型目录、棋盘分布及 v3 格式比例不同，不能把两组绝对损失的变化归因于模型改进或棋力变化。两次都没有按棋局聚类置信区间、时间盲测、合法手重放或等时对局。

当前头在数学上只是归一化的着法分类器，尚未实现文本 CLM 的变化序列编码或跨候选推理。因此现有证据**不支持把固定着法头当作可部署的 CLM 收益**；按照 [阶段门](03-训练与验证协议.md)，不继续为它增加引擎或模型导出工作。

## 3. Q 标签的后续价值与边界

本包提供 Q 候选标签，比第一次归档更适合检查**单步已搜索候选**的覆盖率。官方[三通道编码](https://github.com/lightvector/KataGo/blob/352de42b663862251343d863cb6d6edb11c122cc/cpp/dataio/trainingwrite.cpp#L363-L383)分别为当前落子方 win-loss ×32,000、目差 ×60、访问数（上限 32,000）。`visits=0` 不是非法或坏着；候选筛选必须要求正访问数、足够访问门槛和可靠 Q 差。[`audit_q_candidates.py`](audit_q_candidates.py)对全部 1,800 个抽样文件再次比对 SHA，并对访问数和 Q 数值作 fail-closed 检查；异常计数均为 0。[Q 审计 JSON](runs/2026-09-27-aug20/q_candidates.json)记录完整口径。

| 每行候选覆盖，75,726 个合格局面 | 至少 2 着 | 至少 4 着 | 同时最大/最小 Q 胜负差 ≥0.1：至少 2 / 4 着 |
| --- | ---: | ---: | ---: |
| 每着访问数 ≥8 | 74,976 | 65,093 | 58,147 / 50,313 |
| 每着访问数 ≥16 | 64,382 | 31,988 | 31,484 / 13,180 |

访问门槛 8/16 只是**探索性覆盖筛选**，不是官方可靠性认证。Q 来自同一搜索，候选间估计相关，数值差也可能含噪；这些数量不能直接当 hard negative 质量、CLM 增益或棋力证据。

这仍只有**单步动作**，没有可合法重放的连续 4–8 手 PV；不能直接训练或验证规划中的完整变化 CLM。即使 Q 覆盖足够，也需按候选访问数、搜索稳定性和规则/komi 分层，并与等参数普通候选重排器、额外搜索 visits 比较。新包也没有实际模型权重/导出链，不能进入 B11 兼容模型或引擎接入。

主要复现命令（从仓库根目录运行；抽样目录已存在时无需重复抽取）：

```bash
research/jev-clm-go/.venv/bin/python research/jev-clm-go/census_tar.py \
  research/jev-clm-go/2026-08-20npzs.tgz \
  --output research/jev-clm-go/runs/2026-09-27-aug20/archive_census.json
research/jev-clm-go/.venv/bin/python research/jev-clm-go/prepare_tar_sample.py \
  research/jev-clm-go/2026-08-20npzs.tgz --count 1800 \
  --out-dir research/jev-clm-go/data/2026-08-20npzs
research/jev-clm-go/.venv/bin/python research/jev-clm-go/audit_npz.py \
  research/jev-clm-go/data/2026-08-20npzs --full-board-only \
  --output research/jev-clm-go/runs/2026-09-27-aug20/audit.json
research/jev-clm-go/.venv/bin/python research/jev-clm-go/train_probe.py \
  research/jev-clm-go/data/2026-08-20npzs \
  --out-dir research/jev-clm-go/runs/2026-09-27-aug20/main \
  --full-board-only --device mps --split-seed clm-v1-aug20-main-2026-09-27 \
  --seeds 11,29,47 --epochs 5 --head-dim 256 --batch-size 128
research/jev-clm-go/.venv/bin/python research/jev-clm-go/audit_q_candidates.py \
  research/jev-clm-go/data/2026-08-20npzs \
  --audit research/jev-clm-go/runs/2026-09-27-aug20/audit.json \
  --output research/jev-clm-go/runs/2026-09-27-aug20/q_candidates.json
```

抽样器会拒绝覆盖已存在的同名 `data/`；重跑训练请另设 `--out-dir`，保留这次结果。
